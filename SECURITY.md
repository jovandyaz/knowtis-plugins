# Security Policy

## Supported versions

Security fixes are applied to the latest plugin versions listed in each
`.claude-plugin/plugin.json` manifest.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's
[private vulnerability reporting](https://github.com/jovandyaz/knowtis-plugins/security/advisories/new)
and include the affected plugin or command, impact, reproduction steps, and any
proposed mitigation.

Never include credentials, connection strings, production data, or private
Knowtis repository content in a report. You should receive an acknowledgement
within seven days.
